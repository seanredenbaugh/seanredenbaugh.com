I am excited to announce that the Kindle version of my first novel, Sunlight Parted, is now available on the Amazon website. It’s only $6.39! So head on over to www.Amazon.com and type my name – “SEAN REDENBAUGH” into the search bar. You will find both of my books on there.

Right now only the digital eBook is available in ePUB format, so all ePUB readers can read it, but it will eventually be in actual print when the setup is all done. I think that will be in the next 2-3 weeks, and I’m very excited about being able to hold it in my hands. The 5.25×8 inch paperback will be $16.95 retail. Some websites might list it for more or less, but it should be on all of them, so shop around.
